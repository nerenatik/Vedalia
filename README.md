# Ведалія — образовательный сайт о Беларуси

Статический учебный сайт: история, культура, природа и белорусский язык.
Без сборки и зависимостей — достаточно открыть `index.html` в браузере.

Название «Ведалія» придумано специально для проекта: от белорусского «веды»
(знания) — «земля знаний».

Онлайн-версия: <https://nerenatik.github.io/Vedalia/>

## Разделы

| Страница | Что внутри |
|---|---|
| `index.html` | Главная: обзор, факты о стране, учебный прогресс |
| `history.html` | 18 ключевых событий с фильтром по эпохам |
| `culture.html` | 6 тем: традиции, литература, музыка, архитектура, кухня, ремёсла |
| `nature.html` | География, 6 областей, парки, реки и озёра |
| `language.html` | Алфавит, карточки слов, разговорник с озвучкой |
| `quiz.html` | Тест из 20 вопросов с объяснениями и разбором ошибок |

## Возможности

- **Учебный прогресс** — кнопка «Отметить как изученное» в конце каждого раздела.
  Прогресс сохраняется в `localStorage` браузера и отображается на главной.
- **Тёмная и светлая тема** — переключатель в шапке, выбор запоминается.
- **Тест** — случайный порядок вопросов, объяснение после каждого ответа,
  разбор ошибок и сохранение лучшего результата.
- **Карточки слов** — переворачиваются по клику или с клавиатуры.
- **Озвучка фраз** — через Web Speech API (качество зависит от голосов в системе).
- **Адаптивная вёрстка** — от 320 px до широких экранов.

## Как запустить

Вариант 1: дважды щёлкнуть `index.html`.

Вариант 2 (если браузер ограничивает локальные файлы):

```bash
cd belarus
python -m http.server 8000
```

Затем открыть <http://localhost:8000>.
